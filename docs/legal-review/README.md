# docs/legal-review/

FreeGroup2 ライセンス文書群（LICENSE.md / CLA-individual.md / CLA-corporate.md）の **人間の士業（弁護士・税理士）による正式レビュー前の事前整理資料** を格納するディレクトリです。

---

## 目的

LICENSE.md / CLA-individual.md / CLA-corporate.md の各草案を、人間の士業による正式レビューに提出する前に、論点の網羅性と修正方向性を磨き上げることを目的としています。

AIによる事前レビューを活用することで、人間の士業に提示する依頼書の完成度を高め、士業の作業時間を短縮することを狙いとしています。

**重要：** AIによる事前レビューは、あくまで論点整理のための「たたき台」であり、最終的な法的判断・税務判断は人間の士業による正式レビューを経て確定します。

## 利用順序

人間の士業がこの資料を参照する想定の順序：

1. **`05_依頼書_v1_1_rev5_草案.md`** を主資料として最初に読み、確認ポイント（17項目）と各論点へのAIレビュー反映状況の全体像を把握する。rev5 は rev4 に3つのAIレビューを統合・反映した版であり、**正式レビューは rev5 を優先して参照**してください。
2. 必要に応じて **`01_依頼書_v1_1_rev4_草案.md`**（rev5 のベース）を参照し、rev5 で追記・追加された箇所との差分を確認する。
3. 続いて **`03_AIレビュー_Opus_弁護士役.md`** および **`04_AIレビュー_Opus_税理士役.md`** を読み、rev5 に反映された個々の指摘・修正案の原典を確認する（Opusの方が論点が深いため Gemini より先に参照することを推奨）。
4. 必要に応じて **`02_AIレビュー_Gemini.md`** を参照し、別AIの観点も確認する。
5. 上記（rev4 → 3つのAIレビュー → rev5 の流れ）を踏まえて、rev5 に対する正式レビュー意見を提示する。

## 注意事項

- 本ディレクトリ内のAIレビューは、AIによる事前整理であり、最終的な法的判断・税務判断は人間の士業によるレビューを経て確定します。
- AIレビューには断定的な記述が含まれますが、これは「逃げの文言を避けて踏み込んだ意見を提示してほしい」という依頼意図に基づくものです。最終判断は人間の士業に委ねられます。
- 各AIレビューは、依頼時点での草案（main ブランチの LICENSE.md / CLA-individual.md / CLA-corporate.md）を対象としています。今後の改訂により、参照すべき条文番号や条文内容が変わる可能性があります。
