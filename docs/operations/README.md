# docs/operations/

FreeGroup2 の**事業運用に関する手続き・ルールを定める運用ドキュメント**を格納するディレクトリです。

製品の機能仕様（`docs/specs/`）でも、ライセンス文書の士業レビュー素材（`docs/legal-review/`）でもない、「**制度・運用の手続き**」を扱う文書をここに集約します。

---

## 目的

LICENSE.md が定める各種制度（登録制度・登録料等）を、実務として運用するための詳細ルールを明文化することを目的としています。

- フォーム実装・システム化の基準ドキュメント
- 募集・審査・承認・退会など運用手順の確定
- 審査運用プロンプト設計の元データ
- LICENSE.md 改訂・プライバシーポリシー追記の前提資料

これらの文書は**内部運用文書**であり、公開ドキュメントサイト（docs.freegroup.work / `docs-site/`）には掲載しません。一般向けの案内が必要な場合は、各運用文書から要約を抽出した別ページとして切り出します。

---

## ファイル構成

| ファイル | 内容 |

| `README.md` | 本ファイル（ディレクトリの索引）。 |
| `ディストリビュータ登録制度運用仕様書_v0_1.md` | ディストリビュータ（登録事業者）登録制度の運用詳細。LICENSE.md v1.0.1 第5条の運用版。新規登録・年次更新・退会・データ保持・審査フロー・別表4種を収録。**草案（v0.1）**。 |

---

## 利用順序

1. まず **`ディストリビュータ登録制度運用仕様書_v0_1.md`** の第1章（位置づけ）・第2章（全体像）を読み、本制度と LICENSE.md 第5条の対応関係を把握する。
2. 実装目的（フォーム実装）であれば、**別表2（登録入力項目一覧）・別表3（退会後データ取扱い）・第9章（実装メモ）** を参照する。
3. 審査運用が目的であれば、**第3章3.4（審査フロー）・第7章（書類確認）** を参照する。
4. LICENSE.md・プライバシーポリシーへの反映状況を確認したい場合は、**第10章（反映待ち事項）** を参照する。

---

## 正本との関係

- 本ディレクトリの文書は、`LICENSE.md` を**正本**とする運用詳細です。記述が食い違った場合は **LICENSE.md が常に優先**します。
- 各文書で確定した運用のうち LICENSE.md・プライバシーポリシーに未反映のものは、各文書内の「反映待ち事項」章で管理します（ディストリビュータ登録制度運用仕様書では第10章）。

---

## バージョン運用

- 草案は `v0_1` から始め、LICENSE 改訂やフォーム実装で内容が確定した段階で `v1_0` へ更新します。
- 各文書の冒頭に改訂履歴テーブルを置き、対応する LICENSE.md の版（v1.0.1 等）も記録します。
