## 凡例

### ステータス

| 値         | 意味                                                       |
| ---------- | ---------------------------------------------------------- |
| **採用**   | 現在有効な決定                                             |
| **撤回**   | 過去に採用されたが取り消された決定（理由は本文に記載）     |
| **改訂**   | 過去に採用されたが内容が変更された決定（差分は本文に記載） |
| **検討中** | まだ確定していない決定（議論進行中）                       |

### 影響範囲の書き方

- **プロジェクト全体**：FreeGroup2 全体に効く決定（運用ルール、ライセンス方針など）
- **v1.x.y**：特定のバージョンに紐づく決定
- **v1.x.y `<フェーズ名>`**：特定フェーズに紐づく決定（例：`v1.6.0 mailing`）
- **`<モジュール名>`**：特定モジュールに紐づく決定（例：`OCR`、`認証`）

複数該当する場合はカンマ区切り（例：`v1.6.0 mailing, OCR`）。

## 運用ルール

### 追加するとき

1. `decisions/TEMPLATE.md` をコピーして `decisions/YYYY-MM-DD_<議題名>.md` を作成する
2. 本ファイル（INDEX.md）の表に 1 行追加する（最上段）
3. 最終更新日を更新する

### 状態を変えるとき（採用 → 撤回 / 改訂）

1. 該当する個別ファイル本文のステータスを更新し、撤回・改訂の理由を追記する
2. 本ファイルの表のステータスを更新する
3. 最終更新日を更新する

### ファイル名規約

- 形式：`YYYY-MM-DD_<議題名>.md`
- 議題名は日本語可、スペースは使わずアンダースコア
- 例：`2026-05-26_claude_code運用開始.md`、`2026-05-15_スコープ最小原則.md`
