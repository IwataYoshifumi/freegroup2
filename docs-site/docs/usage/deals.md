# 案件管理

商談・案件（`Deal`）の作成からステータス管理、関係者・添付ファイルの管理までを説明します。

## 案件の作成

案件は次のいずれかの画面から起票できます。

- 会社詳細画面から「案件を作成」
- 人物（Person）詳細画面から「案件を作成」
- メール配信キャンペーンの反響（クリックしたリンク等）から起票

人物詳細画面から作成した場合、その人物が案件の主担当窓口として自動的に登録され、会社が未指定であれば、その人物のコンタクト情報から会社も自動的に引き継がれます。

案件の作成は複数ステップからなるウィザード形式になっており、基本情報の入力後、関係者の登録・添付ファイルの登録へと進みます（各ステップは後からいつでも案件詳細画面からやり直せます）。

## 案件一覧・カンバン画面

案件は次の 8 つのステージのいずれかを持ちます。初回接触・ヒアリング・提案の 6 段階（進行中ステージ）と、成約・失注の 2 段階（クローズ済みステージ）に分かれます。

一覧画面は、通常の一覧表示のほか、ステージ別に案件を並べる**カンバン表示**に切り替えられます。カンバン表示では、ステージ（列）ごとの案件金額の合計も表示され、案件のパイプライン状況を俯瞰できます。

**カンバン画面はステージ別の表示専用です。カンバン上で案件をドラッグ&ドロップしてステージを直接変更することはできません。** また、成約・失注となった案件はカンバンの列には表示されません（進行中の案件のみが対象です）。

ステージを変更する場合は、後述のとおり案件の編集画面またはクローズ画面から行います。

## ステージの変更

- **進行中ステージ間の変更**（初回接触〜提案の6段階の間での移動）：案件の編集画面から変更します
- **成約・失注への変更**：編集画面ではステージを成約・失注に変更できません。専用の「クローズ」画面から、成約日・失注理由（失注の場合は必須）などを入力して変更します

**進行中ステージ間の変更履歴は記録されません。** 成約・失注に変更した際の履歴（クローズ日時等）のみが記録されます。

## 担当者・主担当窓口の引き継ぎ

案件には、社内の担当者（オーナー）と、社外の主担当窓口（先方の主要な人物）がそれぞれ 1 名設定されます。異動や担当変更があった場合は、案件詳細画面から専用の引き継ぎ画面を開き、新しい担当者・主担当窓口を選び直します。

## 案件のアーカイブ

不要になった案件は詳細画面からアーカイブできます。アーカイブは論理的な非表示化であり、削除ではありません。

## 関係者管理

案件には、担当者・主担当窓口とは別に、複数の関係者を役割付きで登録できます。

- **社外の関係者**（決裁者・窓口・技術担当・同席者など）
- **社内の関係者**（主担当・サポート・承認者・オブザーバーなど）

関係者は個別に追加・削除できるほか、検索して複数名をまとめて登録する一括登録にも対応しています。社内の関係者には、その関係者が案件を編集できるかどうかを個別に設定できます（担当者以外がアーカイブや担当引き継ぎを行うことはできません。詳しくは [ユーザー管理](users.md) の権限の説明を参照してください）。

## 添付ファイルの管理

案件詳細画面から、見積書・提案資料などのファイルを添付できます。1 ファイルあたり 15MB までのサイズ制限があり、一部の拡張子は安全のためアップロードがブロックされます。

## 現時点でできないこと

- 「最終接触日から○日間、接触のない案件」を条件に一覧を絞り込む機能は、現時点ではありません（最終接触日は一覧に表示・並び替えは可能です）
