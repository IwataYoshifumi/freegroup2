# メール配信のシステム設定

メール配信機能全体に関わるシステム設定（`/mailings/config/`）について説明します。この設定は管理者権限を持つユーザーのみが変更できます。

## 特定商取引法（特電法）対応の必須項目

メルマガ形式で配信する場合、法令で表示が義務付けられている情報をあらかじめ設定しておく必要があります。

- 会社名
- 会社住所
- 配信停止に関する問い合わせ先（メールアドレス・電話番号・URLなど）

これらは配信されるメールのフッターに使用される情報です。未入力のままメルマガ形式の配信を行うことはできません。

## デフォルトの差出人情報

メルマガ形式のキャンペーンで使う、既定の差出人メールアドレス・差出人名を設定できます。キャンペーンごとに個別の差出人情報を指定することも可能です。

## 送信ドメインの制限

メルマガ形式の差出人アドレスとして使用を許可するドメインを設定できます。ここで設定したドメインの配下でなければ、メルマガ形式のキャンペーンの差出人として使用できません（詳しくは [キャンペーン管理](campaigns.md) の「送信ドメインの制限」を参照してください）。

この設定画面にはDKIM関連の入力欄（対象ドメイン・セレクタ・秘密鍵）もありますが、**これらは現時点では機能しません。DKIM電子署名の機能自体が未実装のためです。**

## 現時点で扱っていない機能

このページでは、以下の機能については扱いません。**現時点でシステムに実装されていないためです。**

- DKIM電子署名によるメール認証
- SPF/DKIM/DMARCの設定ガイド画面
- SPF/DKIM/DMARCの診断ツール画面

これらは将来のバージョンで対応が予定されている機能です。実装され次第、このページに追記します。
