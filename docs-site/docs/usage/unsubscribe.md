# 配信停止とブロックリスト

メール配信の配信停止（unsubscribe）の仕組みと、配信対象から除外されるブロックリストについて説明します。

## 受信者側の配信停止フロー

配信されたメールには、配信停止用のリンクが記載されています。このリンクには有効期限がありません。古いメールに記載されたリンクからの配信停止であっても、必ず有効な操作として受け付けられます。

配信停止は次の2段階で行われます。

1. リンクをクリックすると、対象のメールアドレス（一部マスク表示）を示す確認画面が表示されます（この時点ではまだ配信停止は実行されません）
2. 確認画面で操作を確定すると、配信停止が実行され、完了画面が表示されます

2段階に分けているのは、メールソフトによる自動的なリンクの先読み（プリフェッチ）で意図せず配信停止されてしまうことを防ぐためです。

## 配信停止の扱いの違い（個人アドレス／代表アドレス）

配信停止の対象になったメールアドレスの種類によって、扱いが分かれます。

- **個人のメールアドレス**：その人物（Person）自体が配信停止として記録されます。同じ人物に統合されている他のコンタクトも含めて、以後配信対象から外れます。
- **`info@`・`sales@` のような代表アドレス**：特定の個人ではなく、**そのメールアドレス自体**がブロックリストに登録されます。代表アドレスは複数の人物が共有している可能性があるため、人物単位ではなくアドレス単位で扱われます。

## 管理者による代理操作

管理者は、人物の詳細画面から、その人物に代わって配信停止・配信再開（配信停止の取り消し）を行えます。電話等での申し出に対応する場合などに使用します。

## ブロックリスト

配信不能なメールアドレス（ハードバウンスが発生したアドレスなど）や、代表アドレスからの配信停止申請は、ブロックリストとして別途管理されます。

**ブロックリストに登録されたメールアドレスは、キャンペーンごとの設定に関わらず、常に配信対象から除外されます。** 管理画面からブロックリストの一覧確認・登録・取り消し（再送信を許可する）が行えます。

## メルマガ形式での配信停止者の扱い

キャンペーンには「配信停止者にも送るか」を切り替える設定がありますが、**差出人をメルマガ形式にした場合は、この設定に関わらず配信停止者は常に除外されます。** 特定商取引法（特電法）対応のための仕様であり、変更できません（この設定を無効にできるのは、メルマガ形式以外の配信のみです）。
