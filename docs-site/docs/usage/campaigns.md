# キャンペーン管理

メール配信（メルマガ・お知らせ配信）の作成から送信、配信結果の確認までを説明します。宛先となるメーリングリストの作り方は [メーリングリスト管理](mailing-lists.md) を参照してください。

## キャンペーンの作成

キャンペーンの作成は、まず名前だけを入力して作成します。件名・本文・宛先のメーリングリスト・差出人・配信日時といった詳細は、作成後のキャンペーン詳細画面からまとめて設定していきます。詳細画面はキャンペーンに関するすべての操作（編集・テスト配信・予約・レポート確認など）の入口になっています。

## ステータス

キャンペーンは次の順にステータスが遷移します。

`下書き` → `予約済み` → `配信中` → `完了`（送信失敗があった場合は `失敗`）

`下書き` の間は自由に編集できます。`予約済み` にするには、宛先のメーリングリスト・件名・本文・未来の配信日時がすべて設定されている必要があります。予約後、配信が始まる前であれば `下書き` に戻すこともできます。

## テスト配信とプレビューの違い

- **テスト配信**：実際に1通のメールが送信されますが、**宛先は必ず操作した本人（ログイン中のアカウント）のメールアドレスに固定**されており、他の人に送ることはできません。テスト配信はクリックトラッキングや配信履歴の記録対象にはならず、後述の配信レポートには一切反映されません。
- **プレビュー**：実際の宛先候補1名分を選んで、差し込み文言（氏名・会社名など）が正しく埋め込まれた状態の件名・本文を画面上で確認できます。メールは送信されず、DBへの記録も一切ありません。

## 本番配信

配信予約されたキャンペーンは、内部で1分間隔で動いている定期処理が拾って実際に送信します。配信が始まった時点で、宛先のメーリングリストは自動的に凍結されます（詳しくは [メーリングリスト管理](mailing-lists.md) を参照）。送信中に一部の宛先で失敗しても、次の定期処理のタイミングで自動的に再試行されます。

## クリックトラッキング

配信した本文中のリンクは、クリック状況を計測できる形式に自動的に置き換えられます。

- リンクごとのクリック数
- 誰がそのリンクをクリックしたか（人物単位の一覧）

を配信レポート画面で確認できます。

**開封計測（メールを開いたかどうかの確認）は、現時点では実装されていません。** 確認できるのはリンクのクリック状況のみです。

## 配信レポート

キャンペーン詳細画面から配信レポートを開くと、以下を確認できます。

- リンク別のクリック数集計
- クリックした人物の一覧（特定のリンクに絞り込みも可能）
- バウンス（不達）した人物の一覧
- 配信停止した人物の一覧
- 上記をまとめたCSVのダウンロード

## 送信ドメインの制限

差出人をメルマガ形式（自社のニュースレターとしての配信）にする場合、差出人アドレスのドメインが、システム設定であらかじめ許可されたドメインの配下と一致しているかどうかがチェックされます。一致しない場合はエラーとなり配信できません。

**この機能は、差出人アドレスのドメイン名を文字列として照合しているだけの機能です。** 以下の点にご注意ください。

- **DKIM電子署名によるメール認証は、現時点では実装されていません。** システム設定画面にDKIM関連の入力欄はありますが、実際に署名を行う機能はまだ動作しません。
- **SPF/DKIM/DMARCの設定ガイド画面・診断ツール画面も、現時点では実装されていません。**

設定方法については [メール配信のシステム設定](mailing-config.md) を参照してください。
