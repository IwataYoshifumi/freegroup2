# メーリングリスト管理

メール配信の宛先となるメーリングリストと、その絞り込みに使うタグの管理方法を説明します。

## タグ管理

### タグとカテゴリ

タグは、メーリングリスト機能とは別の「タグ」機能で管理します。タグは必ず1つのカテゴリ（業種・役職・展示会名など）に属します。カテゴリ・タグそれぞれに一覧・作成・編集・アーカイブの画面があります。

### 人物への付与

人物（Person）へのタグ付与は、次の3通りの方法があります。

- **個別付与**：人物詳細画面から、1件ずつタグを付与・解除する
- **個別一括変更**：人物詳細画面から、その人物に付けるタグの一覧をまとめて設定し直す
- **検索結果への一括付与**：人物を検索し、ヒットした人物全員に対してまとめてタグを付与する（1回の操作で最大500人まで）

**タグは自動では付与されません。** メーリングリストのメンバーになったからといって、そのメンバーにタグが自動的に付くことはありません。逆に、タグはメーリングリストを作成する際の**絞り込み条件としてのみ**使われます。タグとメーリングリストの間に、それ以上の連動関係はありません。

## メーリングリストの作成

メーリングリストは、次の4ステップのウィザードで作成します。

1. リストの名前・説明を入力する
2. タグの条件を指定する（カテゴリ内での複数タグのOR/AND、カテゴリ単位でのNOT条件、全体からの除外条件を組み合わせられます）
3. 条件に一致する人物の件数・内容を確認する
4. 確定する

**確定した時点で、条件に一致する人物がその場でメーリングリストのメンバーとしてコピーされます。** これは「保存された検索条件」ではなく、確定した瞬間の人物の集合をそのままメンバーとして固定するものです。そのため、後からタグの付与状況が変わっても、すでに作成済みのメーリングリストのメンバーには影響しません。

## メーリングリストの編集と「凍結」

作成したメーリングリストは、そのままではまだ完全に固定されているわけではありません。詳細画面から、メンバーを個別に追加・削除したり、タグ条件で一括追加・削除したりできます。

**メーリングリストが完全に固定される（凍結される）のは、そのリストを宛先にしたキャンペーンが実際に配信を開始した瞬間です。** 凍結のための手動ボタンはありません。配信が始まると自動的に凍結され、以降はメンバーを増やすことはできなくなります（凍結後にできるのは、誤って含まれていた人物をメンバーから除外する操作のみです）。

一度配信に使われたメーリングリストは、内容を検証可能な状態のまま保持するため、このような一方向の仕組みになっています。

## メンバー一覧のエクスポート

メーリングリストの詳細画面から、メンバー情報をCSV形式でダウンロードできます。出力する項目（氏名・会社名・メールアドレスなど）は画面上で選択できます。
