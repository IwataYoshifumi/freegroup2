# 会社管理

コンタクトの「会社名」情報をもとに管理される `Company`（会社）と、重複した会社レコードを 1 つに統合する機能について説明します。

## 会社の一覧と検索

メニューから「会社一覧」を開くと、登録されている会社が一覧表示されます。

### 絞り込みフィルタ

以下のステータスで絞り込めます。

| ステータス | 意味 |
| --- | --- |
| `active` | 稼働中の会社 |
| `archived` | アーカイブ済み（手動で操作） |
| `merged` | 別の会社に統合され、自身は無効化された |

### 検索

画面上部の検索ボックスにキーワードを入れると、社名・ドメイン・電話・住所を横断してフリーワード検索できます。

## 会社詳細画面

一覧から行をクリックすると詳細画面に移動します。詳細画面では、その会社に関する情報を横断的に確認できます。

- 紐づくコンタクト一覧
- 進行中の案件（[案件管理](deals.md) 参照）
- それらの案件に紐づく活動記録（[活動記録](activities.md) 参照）

## 会社情報の編集・アーカイブ

詳細画面から「編集」を開くと、社名・ドメイン・電話・住所・ウェブサイトを編集できます。

不要になった会社は「アーカイブ」できます。アーカイブは手動操作であり、削除とは異なり記録は残ります。

会社の新規作成専用の画面は用意されていません。会社は、コンタクトの会社名情報をもとに自動生成される、または後述の重複統合の結果として生成されるものであり、手動で「会社を新規作成する」操作は基本的に発生しません。

## 会社への自動紐付けについて

コンタクトに会社名が設定されると、その内容をもとにコンタクトと会社（Company）の紐付けが行われます。一致する会社が見つからない場合は、新しい会社レコードが自動的に作成されます。

**この紐付け処理は、コンタクトの登録・編集操作と同時（即時）には行われません。** 内部的には 5 分間隔で動作する定期処理（`link_companies`）がまとめて処理する仕組みになっているため、コンタクトを登録・編集した直後の数分間は、会社がまだ紐づいていない状態になることがあります。急いで会社詳細画面を確認する場合は、数分待ってから再度ご確認ください。

## 重複会社の検出・統合

同じ会社が、社名の表記ゆれやドメイン違いなどにより複数のレコードとして登録されてしまうことがあります。FreeGroup2 は、コンタクト情報から会社名・ドメイン・電話・住所・ウェブサイトを突き合わせて、重複の可能性がある会社の組み合わせを自動的に検出します。

### 確度の区分

検出された組み合わせには、一致の確からしさに応じて次のいずれかの区分がつきます。

| 区分 | 目安 |
| --- | --- |
| 完全一致 | 社名と、ドメインまたはURLの両方が一致し、一致度が高い |
| 可能性が高い | 完全一致に近いが、一致度がやや下がる |
| 可能性が中程度 | 社名・ドメイン・URLのいずれかが一致している |
| 可能性が低い | 社名またはドメインの一致に加えて、電話または住所の一致もある場合のみ候補となる |

電話番号や住所だけが一致していても、それだけでは重複候補として扱われません（同じビルに入居する別会社や、共有の代表番号などによる誤検出を防ぐためです）。

### レビュー画面での判断

「重複候補」画面を開くと、確度の区分ごとにグループ化された候補が表示されます。各グループには、判断の参考になる一致理由（社名一致・ドメイン一致・電話一致・URL一致・住所一致）と、会社ごとの情報の違いが分かるように表示されます。

グループの先頭には、統合先（生存させる会社）の候補があらかじめ表示されます。この候補は**登録が古い会社ではなく、社名・ドメイン・電話・住所・ウェブサイトなど、情報が最も多く埋まっている会社が自動的に選ばれます**（情報量が同じ場合は登録が古い方が優先されます）。内容を確認し、必要であれば別の会社を統合先として選び直せます。

担当者は、それぞれの候補グループに対して次のいずれかを判断します。

- **統合する**：選んだ会社を残し、他の会社に紐づくコンタクト・案件をすべて引き継いだうえで、統合された側は `merged` ステータスになります
- **別会社として確定する**：今後、自動的に重複候補として再表示されないよう、明示的に「別の会社である」と記録します

一度統合すると、統合された会社は編集・単独表示ができなくなります（詳細画面等では統合先の会社に自動的にまとめられます）。統合前に内容をよく確認してください。
