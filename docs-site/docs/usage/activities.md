# 活動記録

電話・訪問・メール・Web会議などの活動記録（`Activity`）の付け方と、日報的な一覧の使い方を説明します。

## 活動記録の作成

以下のいずれかの種別で活動記録を残せます。

- 電話
- 訪問
- メール
- Web会議
- その他

活動記録は、会社詳細画面・人物詳細画面・案件詳細画面のいずれからも作成できます。案件に紐づけて記録した場合、その案件にすでに登録されている関係者（社外・社内）の情報が活動記録側にも自動的に引き継がれます（同じ関係者が重複して登録されることはありません）。案件に紐づけない、会社・人物単位の一般的な活動記録として残すこともできます。

## 活動記録の一覧

活動記録の一覧画面は、既定では**「本日・自分が実施した活動」だけを表示する日報的な画面**として開きます。必要に応じて次の条件で絞り込めます。

- 担当者（実施者、複数選択可）
- 同行者（複数選択可）
- 活動種別（電話・訪問・メール・Web会議・その他）
- 方向（発信／受信）
- 日付・期間
- キーワード（タイトル・メモ・場所・案件名・会社名・関係者名を横断検索）

## 活動記録の編集・アーカイブ

詳細画面から編集・アーカイブができます。アーカイブは論理的な非表示化であり、削除ではありません。

## 関係者管理

案件と同様に、活動記録にも社外・社内それぞれの関係者を役割付きで登録できます。個別の追加・削除のほか、検索してまとめて登録する一括登録にも対応しています。なお、活動記録を実施した本人を、あらためて社内の同席者として登録することはできません。

## 添付ファイルの管理

訪問時に受け取った資料など、活動記録にもファイルを添付できます。案件の添付ファイルと同様、1 ファイルあたり 15MB までのサイズ制限があり、一部の拡張子はアップロードがブロックされます。

## メール配信キャンペーンの未フォロー反響一覧

メール配信キャンペーン内のリンクをクリックした人物のうち、まだフォローの活動記録が残っていない人物だけを一覧表示する画面があります。反響があった相手への対応漏れを防ぐために利用します（すでに別の人物に統合された相手も正しく判定されます）。
