# FreeGroup2 v1.6.1

**リリース日**：2026-05-26
**GitHubタグ**：[v1.6.1](https://github.com/IwataYoshifumi/freegroup2/releases/tag/v1.6.1)

## リリース概要

FreeGroup2 v1.6.1 は、名刺管理機能（コンタクトDB）をリリース版として確定したバージョンです。AI-OCR による名刺の自動データ化、多言語対応、重複検出・人物統合、認証・認可・LDAP 連携までを含む、業務利用可能な状態に到達しました。

## 主要機能

### 名刺管理（コンタクトDB）

- 名刺画像のアップロードと自動データ化
- 4層データモデル（OriginalImage → BusinessCard → Contact → Person）
- Contact のライフサイクル管理（active / archived / merged）
- 手動入力による Contact 作成

### AI-OCR

- Claude Sonnet 4.6 による高精度な名刺情報抽出
- OpenCV による名刺領域の自動検出と透視変換
- 縦書き名刺への対応
- 信頼度メタデータ（high / mid / low）の管理

### 多言語対応

- 日本語・英語・中国語・韓国語等の名刺に対応
- 言語別の宛名組み立てルール（敬称の自動生成）

### 重複検出・人物統合

- バックグラウンドでの自動重複検出
- 同一人物の Contact を Person に統合するマージ機能
- マージ履歴の管理と復元機能

### 認証・認可・LDAP

- ユーザー認証とアクセス制御
- LDAP サーバーとの連携によるユーザー管理
