# FreeGroup2 v1.8.0

**リリース日**：2026-09-15
**GitHubタグ**：mainブランチへのマージ後に作成予定です。

## リリース概要

FreeGroup2 v1.8.0 は、名刺管理（コンタクトDB）を土台に、**会社管理・案件管理・活動記録**という営業支援の中核機能を追加した、大型のバージョンアップです。あわせて、コンタクトのCSV一括インポート、メーリングリストのCSVエクスポート、メール配信の送信ドメイン制限機能も含まれます。

## 主要機能

### コンタクトのCSVインポート

コンタクト一覧からCSVファイルをアップロードして、複数のコンタクトを一括登録できるようになりました。アップロード後にプレビュー画面で内容を確認してから確定します。詳しくは [コンタクト管理](../usage/contacts.md) を参照してください。

### メーリングリストのCSVエクスポート

メール配信のメーリングリストについて、メンバー情報を出力項目を選んでCSV形式でダウンロードできるようになりました。

### 会社管理

コンタクトの会社名情報から会社（Company）を自動的に管理する機能を追加しました。

- 会社の一覧・検索、詳細画面（紐づくコンタクト・案件・活動記録の横断表示）
- 表記ゆれ等による重複会社の自動検出と、レビュー画面での統合（マージ）

詳しくは [会社管理](../usage/companies.md) を参照してください。

### 案件管理

商談・案件（Deal）を管理する機能を追加しました。

- 会社・人物・メール配信の反響からの案件起票
- 一覧表示と、ステージ別に案件を並べるカンバン表示
- ステージ管理（進行中の6ステージ、成約・失注のクローズ処理）
- 担当者・主担当窓口の引き継ぎ、関係者管理、添付ファイル管理

詳しくは [案件管理](../usage/deals.md) を参照してください。

### 活動記録

電話・訪問・メール・Web会議などの活動記録（Activity）を管理する機能を追加しました。会社・人物・案件のいずれからも記録でき、案件に紐づけた場合はその案件の関係者情報を引き継ぎます。一覧は既定で「本日・自分が実施した活動」を表示する日報的な画面です。詳しくは [活動記録](../usage/activities.md) を参照してください。

### メール配信：差出人ドメインの制限

メルマガ形式で配信する場合の差出人アドレスについて、管理者があらかじめ許可したドメインの配下に限定できるようになりました。許可外のドメインを差出人に指定した場合はエラーとなり、意図しないドメインからの配信を防ぎます。なお、DKIM署名によるメール認証そのものは今後のバージョンで対応予定です。

## 動作環境

- Python 3.13 以上
- Django 6.0.2
- PostgreSQL（本番環境推奨）/ SQLite（開発環境）
